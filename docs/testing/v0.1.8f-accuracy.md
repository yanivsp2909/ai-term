The kernel source is pageable internal (anonymous) pages, not just active pages. `vm_stat`'s Anonymous pages is the matching counter and includes inactive anonymous allocations; subtracting purgeable excludes memory apps can relinquish. Wired and actual physical compressor occupancy complete the user-requested Activity Monitor formula. `Pages stored in compressor` is uncompressed logical size and is not added.

Immediately following sysctl check, argv `/usr/sbin/sysctl vm.page_pageable_internal_count vm.page_purgeable_count`:
```text

```
These commands are sequential, not atomic; the 950-page (~14.84 MiB) internal-memory difference reflects intervening allocations. Product uses the single vm_stat snapshot, avoiding mixed-command counters and a fourth command each second. Activity Monitor simultaneous visual comparison: needs Yaniv. ```text

The parser works for this Mac's output.
