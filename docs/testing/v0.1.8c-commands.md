## Decisions taken without waiting

- Auto is Claude-only; Codex's documented automatic approval reviewer is not a distinct Ask mode and was not substituted. D13 was extended only for the explicitly requested Claude Auto; Ask remains the only saveable default.
- Codex resume help accepts a UUID, but no documented new-session UUID flag/return channel gives AI Term that ID. Use its own cwd-filtered picker without reading any CLI files, as authorized.
- Claude uses the documented direct effort flag, no config-file/settings fallback. Codex uses documented config key + matching source enum. CLI default emits no effort option.
- Mode selection applies to the next session, then resets to Ask after start/cancel. A mode chosen inside the box is preserved across a compatible model selection. Invalid modes/effort reset safely when changing engines.
- /help wraps at narrow widths; command menu clips long values/descriptions within terminal bounds and keeps the highlighted row visible. No animation added.
- Protocol additions are optional effort/conversation metadata plus sessions.resume {sessionId}. Legacy records remain readable, but legacy Claude records cannot resume without their conversation UUID. New UUIDs belong to Claude agents, not login sessions.
- No network for checks. The explicit required git push is the delivery exception to “No network”.
