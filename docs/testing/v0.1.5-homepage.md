## Security checklist

- [x] S15: **S15: OSC 52 / title / bell in a session never reaches homepage stdout** injects controls, checks payload/bell/OSC escapes absent, and parses rendered stdout in an independent terminal to verify safe text appears. Preview bytes enter xterm; stdout receives reconstructed sanitized cells/styles only. Only attach writes raw session bytes.
- [x] Homepage input: **homepage is read-only: no input frame is sent for typing, arrows, paste or mouse** spies on connection.input and checks sessions.create is absent. The homepage connection interface excludes input(). Paste shortcuts remain text.
- [x] S8: `rg -n 'exec\(|execSync|shell: true' src` returned no matches. clipboard.ts calls `execFile('/usr/bin/pbcopy', [], {timeout:2000}, callback)` and `child.stdin.end(text)`. **selection calls pbcopy through execFile with argv array and plain text on stdin** pins that boundary.
- [x] Mouse: **turns homepage mouse reporting off before attach, restores it after home, and resubscribes preview** and **idle homepage writes no redraws and restores mouse/raw/alternate modes on quit and crash**. Shared RESET_MODES disables mouse tracking/encoding before leaving home. Attached applications may enable their own mouse modes as before.
- [x] No key/keychain/credential code changed. env.ts and existing credential implementations are unchanged; no forbidden personal files were accessed. Tests/measurement clean only their own processes/temp roots.

S2 additionally covers theme-only settings and strict session enums; snapshots/events are validated before use. Settings use O_NOFOLLOW, owner/file checks, 0600 and atomic writes. Copy excludes banner rows and unseen remote-terminal columns, and errors are surfaced. Copy feedback is a single 1.2-second information change.

## Performance

Run `python3 scripts/measure-homepage.py` after `npm run build`. The harness starts a private temporary daemon, creates a /bin/sh session, attaches only to run `/opt/homebrew/bin/node spikes/renderer/noise.js`, detaches, then measures the built homepage at 130×45. It drains a real outer PTY and samples `/bin/ps -o %cpu=` once per second after one second of warmup. The gate checks maximum sampled CPU under 15%.

Client CPU includes client xterm parsing/rendering, excludes separate daemon/noise/harness. ps is smoothed and cannot prove instantaneous CPU peaks or physical terminal paint cost. Node v26.3.0 on the local Mac. Raw final numeric evidence is `v0.1.5-homepage-cpu.json`.

First implementation: 12.49% average, 18.2% maximum. It did not establish a stays-under-15% result. Bounded caching avoids repeatedly segmenting static borders/labels; the next run measured 4.28% average, 6.8% maximum over 30.13 seconds, about 3347 stdout bytes/s. Final code was measured again after all review fixes; results are recorded below.

## Corrections and judgments

- Protocol exposed only starting/running/exited/error despite design’s waiting/done/idle vocabulary. Types and strict validators now support those rendering states; no v0.2 hooks were added. Shell sessions now display instead of being hidden as the old comment said.
- `session.previewResized` is an additive event required for remote attach/detach/resize and another homepage resizing detached sessions. Clients request a new dimensioned snapshot rather than assume local layout always controls that session.
- Design’s generic background inheritance wording was ambiguous with fixed palettes. Fixed palettes paint their ground; only auto uses SGR49. Design/token usage text now states this explicitly.
- Architecture attach-response outline omitted modes/current session; README said nothing could run. Docs now match implemented behavior.
- Auto keeps spike rules: luminance threshold, 5/11/24% panel mixing, tertiary contrast adjustment and slate fallback. The fixed threshold can have weak contrast on intermediate-gray terminals; no design decision was reopened.
- Calm choices where unspecified: three-line cards, no fake context percentages, no notification/budget interaction, no age-only live timer (ages refresh on actual changes), and defaults show the launch folder. Nothing animates.

Final-code performance: **30.2002 seconds, 6.8167% average, 12.3% maximum** of one core. All 30 samples under 15%; 3281 stdout bytes/s, 912 synchronized frames, noise visible, exit 0, canonical/signals restored, mouse and alternate screen off. This is the reported result, after all code fixes, rather than the earlier faster observation.

Final targeted security/code/TypeScript re-review through bc89df7 found no remaining issues in the four fixes.
