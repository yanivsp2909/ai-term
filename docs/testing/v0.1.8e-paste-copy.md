## User journeys

- Paste a long or multiline task into the command bar or start message row, see one token, edit around/delete it, and start with the exact full text.
- Reject a whole insertion above the existing first-message byte limit with a visible instruction; never silently cut it.
- Copy the selected session with generic decoration removed. `/copy all` names the whole-session scope; `/copy` and c disclose that exact last reply waits for v0.2.
- Keep pasted/copied contents off logs and disk; use fake copiers and local stubs to prove delivery and isolation.

Escape restoration waits account for the existing background filter plus parser delays. Copy test expectations drop border-only blank rows, as the brief requires; they do not turn those rows into extra blank lines.

- The calmer default is a static token with no new modal or animation. Full paste contents never enter the command bar rendering; the start row previews only its first line. Longer rows clip by cell width using the existing grid.
- Physical Terminal.app paste, real agent receipt and Notes clipboard comparison require Yaniv. Exact last reply remains v0.2 work; no hook/notify code was added. v0.1.9 was not started.
