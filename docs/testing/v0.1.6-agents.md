## Exact manual commands for Yaniv

These use a new temp AI Term home and folder, so your running daemon is unaffected. Keep both terminals pointed at the same printed path.

Terminal 1:
```sh
cd ~/ai-term
AITERM_CHECK_ROOT=$(mktemp -d /tmp/ai-manual-XXXXXX)
printf '%s\n' "$AITERM_CHECK_ROOT"
AI_TERM_HOME="$AITERM_CHECK_ROOT" node dist/cli/index.js
```
On the homepage: `/model`, select Claude CLI default; `/cd`, enter the printed temp folder. Paste `reply with ok`, Enter for confirmation, keep ask, Enter to start. Enter to attach. Review/answer the CLI's folder trust prompt yourself. Observe the reply; Ctrl+E home; confirm it keeps running; `s`, `y` to stop. Repeat with Codex CLI default. If Codex says YOLO, inspect `/permissions` yourself before submitting anything; use `/status` to inspect effective provider through the CLI, without sending credential contents to chat.
