## Codex source and choices

`codex --version` ran with an isolated temporary HOME/CODEX_HOME, no auth commands: `codex-cli 0.160.1`. The matching public source was already present in a temporary checkout from the earlier spike; no source download was made.

- [rust-v0.160.1 session_telemetry.rs](https://github.com/openai/codex/blob/rust-v0.160.1/codex-rs/otel/src/events/session_telemetry.rs#L1102): `sse_event_completed` emits `event.name=codex.sse_event`, `event.kind=response.completed`, `input_token_count`, `output_token_count`, `cached_token_count`, `reasoning_token_count`. Input/output use display formatting and can arrive as strings. Extra `cache_write_token_count`, `tool_token_count`, service tier and effort fields are ignored. Reasoning is not added to output again.
- [rust-v0.160.1 provider.rs](https://github.com/openai/codex/blob/rust-v0.160.1/codex-rs/otel/src/provider.rs#L485): the HTTP JSON log exporter explicitly calls `with_headers(headers)`. No documented env-only header route was found, so the invocation-local `-c` exporter override is used, before `--`/first message. Env and argv never enter logs/state/responses.
- The prompt cited D52, but the checked-in D-log ended at D46. D52 was recorded from the prompt's explicit Codex-header decision. Architecture's older “never argv” sentence and “test #6 confirmed before implementation” premise were updated to the authorized behavior and the actual unrun live check.
- Estimate label: one calm `≈` on spend, `price ?` when any usage is unpriced. Known estimates sum; unknown usage is not guessed. Catalog cache price missing with cached input stays unknown. Explicit two-rate Foundry overrides apply their chosen input rate to all input tokens without guessing a discount.
- Own-login Codex reports API-key vs subscription, not its provider. Its usage is counted under OpenAI using a matching model price. AI Term-keyed Foundry sessions are explicitly Foundry and use Azure prices/overrides. No config/credential inspection was added to infer a provider.
- One authorized Models.dev fetch, 2026-10-12. Trimmed snapshot: Anthropic 17 models, OpenAI 49, Azure 95. Only input/output/cache-read numbers and model identifiers remain. Regeneration script takes an already downloaded file offline.
- Runtime dedupe lasts until session exit; credentials revoked at exit/restart prevent old exporters from reaching the new receiver. Unsaved events retry after write failure, but remain memory-only until disk recovery. Crash durability during a full disk cannot be guaranteed.
- Budget limits are advisory. Unknown costs cannot trigger a monetary limit; `price ?` keeps that visible. Limits and overrides save through existing settings merge validation. No u-details or next roadmap step was started.
