Purgeable = 121,733,120 bytes = **116.094 MiB / 0.113373 GiB**. App+wired+compressed = **27.995529 GiB**; anonymous+wired+compressed = **28.108902 GiB**. First snapshot purgeable 6,526 pages = 101.969 MiB. Ten live diagnostic readings found 64.688–127.203 MiB.

The supplied Activity Monitor parts sum to 27.67 GB, while its headline 28.78 differs by 1.11 GB. The current purgeable amount is roughly one tenth of that difference, so including it would not establish a match and would change a known-correct App/Wired/Compressed sum. **Retained anonymous − purgeable + wired + compressed.** The Activity Monitor headline gap remains unexplained; debug stats exposes both candidates for paired visual evidence. Do not claim the headline is calibrated.

## Debug command

`ai debug stats` does not connect to the daemon. Ten pairs are started one second apart; top startup delays the first result, then output is about one second apart, completing around eleven seconds. Each pair includes top's two-snapshot one-second comparison plus vm_stat numeric parts. Upper bound is ten pairs; normal homepage sampling remains unchanged, with no top calls.

Each JSON line has numeric values only: sample, anonymousBytes, purgeableBytes, appBytes, wiredBytes, compressedBytes, cachedBytes, freeBytes, appWiredCompressedBytes, anonymousWiredCompressedBytes, cpuPercent, topUserPercent, topSystemPercent, topIdlePercent, topBusyPercent. Cached means File-backed pages. Values are bytes, percentages are machine share. Divide byte values by 1,073,741,824 to compare the existing GB display. No raw OS output survives.
